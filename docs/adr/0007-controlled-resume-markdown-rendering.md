# 受控简历 Markdown 与专用渲染模板

`content/resume.zh.md` 是简历内容的唯一真相源，但它不是通用文章 Markdown：技能、经历、项目与教育联系章节需要稳定映射为两页 A4 简历的专用版式。因此 `apps/resume` 采用受控章节合同与专用 Markdown→HTML 模板，并在创建候选内容 Issue 前校验结构；不采用通用 Markdown 页面渲染，以避免编辑后 PDF 的语义和排版漂移。视觉与打印 CSS 以旧 `resume/data/resume.html` 为基线，沿用其页边距、字号、技能网格、项目左导轨和技术栈条。分页器先测量连续内容流，再将同一内容渲染进 N 个固定 A4 裁剪窗口，并按每页可用内容高度偏移；跨页项目块的边界吸附到项目顶部，避免标题、要点和技术栈条被裁断。两页约束不得依靠隐藏、裁切或不可读的字号实现。

**Status**: accepted

**Considered Options**:

- 通用 Markdown 渲染 —— 拒绝：无法稳定表达技能双栏、经历标题和项目技术栈，PDF 排版会随内容结构漂移
- 受控 Markdown 合同 + 专用模板 —— 采纳：内容保持可读可编辑，同时锁定简历所需的语义和版式
